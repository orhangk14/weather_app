# 🌤️ Python Weather App

A command-line weather application built with Python that fetches real-time weather data and forecasts using the OpenWeatherMap API.

## ✨ Features

- 🌡️ Current weather data (temperature, humidity, wind, etc.)
- 📅 5-day weather forecast
- 🌍 Search any city worldwide
- 📏 Toggle between metric (°C) and imperial (°F)
- 🎨 Clean formatted output with emojis
- 🔐 Secure API key handling with `.env`
